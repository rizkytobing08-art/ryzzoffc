Perjalanan saya

  1. 2023

    Kenalan dengan HTML dan CSS

    Perjalanan saya dimulai saat pertama kali berkenalan dengan HTML dan CSS. Sebagai developer pemula dengan semangat tinggi, langkah pertama ini terasa seperti membuka pintu ke dunia yang benar-benar baru.

  2. Lanjut

    Belajar JavaScript

    Sejak saat itu, rasa ingin tahu saya terus berkembang. Saya mulai mempelajari JavaScript, dan halaman web yang tadinya diam mulai terasa hidup dan interaktif.

  3. Naik level

    React dan TypeScript

    Saya melangkah ke React dan TypeScript. Setiap hari adalah kesempatan baru untuk belajar sesuatu yang menarik di dunia programming.

  4. Di sekolah

    SMK Teknik Jaringan (TJKT)

    Saat ini saya siswa SMK jurusan Teknik Jaringan Komputer dan Telekomunikasi (TJKT). Di sekolah saya mempelajari networking dan infrastruktur IT, sementara di waktu luang saya terus mengasah kemampuan web development secara otodidak.

  5. Sekarang

    Menguji performa website

    Mencoba load testing dengan k6 untuk melihat seberapa kuat sebuah website menahan banyak pengunjung. Ini bagian dari misi saya: terus belajar, terus membangun, dan terus berbagi, karena setiap project, sekecil apa pun, adalah langkah menuju developer yang lebih baik.
